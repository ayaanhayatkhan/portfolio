# 🌐 Ayaan Hayat – Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, projects, and contact information.

This portfolio highlights my journey as a **Student Programmer** and serves as a central place to present my work and connect with others.

---

## ✨ Features

* 🎨 Modern and responsive design
* 🌙 Light/Dark theme toggle
* ✨ Interactive cursor glow effect
* 🏠 Hero section with introduction
* 👨‍💻 About Me section
* 💡 Skills showcase
* 📂 Projects section
* 📧 Contact section
* 🔗 GitHub and LinkedIn links
* 📱 Mobile-friendly layout

---

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* Google Fonts (Poppins)

## 🚀 Getting Started

1. Clone this repository:

```bash
git clone https://github.com/ayaanhayatkhan/portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No installation or additional dependencies are required.
